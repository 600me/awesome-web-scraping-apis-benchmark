Method: block_rate and js_share are fractions of first-attempt traffic. M_retry = 1/(1−block_rate); effective_bw_factor = 1 + block_rate/(1−block_rate)×0.35; avg_kb = html_kb×((1−js_share)+js_share×2.4)×effective_bw_factor; real_gb = pages×avg_kb/1,048,576; proxy_cost = real_gb×proxy_gb_price; compute_cost = pages×js_share/100,000×$18; eng_cost = eng_hours×$75. Managed credits = pages×((1−js_share)×1+js_share×5).

Model limits: managed cost assumes only delivered 200 OK pages are billed and failed retries cost zero credits; verify that assumption with the vendor. It excludes storage, vector embedding, LLM inference, taxes, minimum commitments, paid CAPTCHA solvers, proxy failures above the block rate and incident spikes. DIY excludes idle capacity and egress. This is a planning tool, not a quote or a service guarantee.
