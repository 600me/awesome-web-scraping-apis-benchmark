1. The Hidden RAM & Zombie Process Tax of Self-Hosted Chromium PDFs

Engineering teams that already run Playwright or Puppeteer for web scraping often reuse the same headless Chromium image for invoice, report, and contract PDF rendering. Under concurrent load, Chromium's page.pdf() spawns isolated renderer processes consuming 350 MB to 650 MB of RAM per worker, frequently triggering Linux OOM-killer events, zombie Chrome processes, and missing CJK/custom webfont glitches inside Alpine or Debian containers.
